## Made for the MegaETH Community

This project automatically fetches real-time metrics from the **MegaETH testnet** and updates this README every hour using GitHub Actions.

The goal is to visualize key stats like block height, TPS and gas price — and show the power of *web-scale L2* performance.  
Completely serverless, open-source, and running 100% free on GitHub.

Follow updates, fork it, or star the repo to support it!  
Made by [@mikovaj](https://github.com/mikovaj)
